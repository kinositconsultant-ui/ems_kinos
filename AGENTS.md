# Project Instructions

## Project

Company Attendance System.

## Technology

- Python
- Django
- AdminLTE 4
- Git and GitHub
- MySQL, subject to approval

## Rules

- Inspect existing files before editing.
- Do not invent unapproved business rules.
- Never commit passwords, tokens, or secrets.
- Read application secrets from environment variables.
- Use Django ORM and version-controlled migrations.
- Add tests for business logic and permissions.
- Enforce permissions on the server side.
- Never delete or reset databases without approval.
- Do not commit or push without my review.
- Report actual test results.
